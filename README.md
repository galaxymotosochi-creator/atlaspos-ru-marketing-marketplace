# AtlasPos.ru — Marketing Marketplace

Маркетплейс маркетинговых услуг для бизнеса на AtlasPos: исполнители и агентства против заказчиков.

**Разработка:** Bokov777

## Что внутри

Маркетинговый лендинг-хаб под atlaspos.ru — POS-платформа для розницы, сферы услуг и общепита.

### Продуктовые блоки (из брифа)

**Готовые возможности системы**
- Онлайн-запись клиентов — персональная витрина для самостоятельной записи
- Расчёт зарплат — автоучёт смен и начисление выплат тренерам
- Финансовый учёт — чистая прибыль, выручка и расходы без Excel

**Адаптация под типы бизнеса**
| Тип | Что даёт |
| --- | --- |
| Розничная торговля | Сканирование штрихкодов, автосписание, быстрый поиск товаров |
| Сфера услуг | Онлайн-запись, каталог услуг, учёт выработки |
| Общепит и кафе | Калькуляция тех.карт, учёт ингредиентов и полуфабрикатов |
| Смешанный бизнес | Товары и услуги в одном чеке |

**Запуск за 3 шага**
1. Регистрация — 2 минуты, без привязки карты
2. Импорт номенклатуры — из Excel за 10 минут
3. Первый чек — с любого устройства

**Преимущества**
- Бесплатный доступ при продажах до $1000/мес
- Офлайн-режим кассы с последующей синхронизацией
- Кроссплатформенность: iOS, Android, браузер

**Настройка персонала** — приглашение сотрудников с персональными правами доступа.

**Подключение кассы** — способы оплаты, смены, фискализация чеков.
